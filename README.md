# DOORS Scribbles Prank 📄👀

A funny, harmless joke application inspired by the **Scribbles** monster from the Roblox game *DOORS*.

## 📂 Files inside:
* **Scribbles.py** — The main Python script that spawns duplicating Scribbles windows all over the screen when clicked.
* **Scribbles.png** — The original game sprite used for the prank.
* **Scribbles.bat** — An extra script that triggers a 60-second computer restart timer.

## 🛠️ How to stop the pranks:
* **For Python windows:** Press `Ctrl + Shift + Esc` to open Task Manager, find the `Python` process, and click **"End Task"**.
* **For the Restart timer:** Press `Win + R`, type `shutdown -a`, and press Enter to cancel the countdown.
